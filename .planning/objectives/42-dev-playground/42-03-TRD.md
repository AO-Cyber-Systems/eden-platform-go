<objective>
Make it one command, and make the first thing a developer sees be something that works.
</objective>

<the_curl_must_actually_work>
A printed example that 404s or 401s is worse than no example — it costs the developer
trust and twenty minutes. The test for this TRD must EXECUTE the printed command against
the running server and assert success. If the command is generated, generate it from the
same values the server actually used; do not hand-write a string that can drift.
</the_curl_must_actually_work>
