<state_the_boundaries>
The failure mode for a tool like this is someone mistaking it for a staging environment
and trusting it with something real. The README must foreclose that: in-memory, dev-only,
data lost on exit, cannot be compiled into a production binary.

Equally, it must foreclose the opposite error — assuming authorization is fake. It is not.
The developer holds a real token for a real seeded user, and every RBAC decision is
genuine. That is the whole reason this is worth building rather than mocking.
</state_the_boundaries>
